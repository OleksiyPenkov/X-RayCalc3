What the tool gives

XRCUncert takes a project that has been fitted in X-Ray Calc 3 and gives every fitted parameter as value ± error. It works on one model and the one measured curve linked to it. The fit itself is not changed: the tool starts from the fitted model and finds how far each parameter can move before the calculated curve stops agreeing with the measurement.

Starting it

  • In X-Ray Calc 3: Tools > Parameter uncertainties... The project is saved and the tool opens on it.
  • On its own: Open..., or drop a .xrcx file on the window.

Press Run. A line under the buttons shows the time left; a typical run takes about a minute. When the first run does not settle the tool runs once more, longer, and the line says so. Stop ends the run and leaves the project as it was.

The result is stored inside the project file, so it is there the next time the project is opened in the tool, and it travels with the file. Saving the project in X-Ray Calc 3 keeps it.

What it takes from the project

From the projectHow it is used
The active model and its linked curveThese are what is analysed. Link the curve to the model in X-Ray Calc 3 first.
The fitting modePeriodic, Profile or Irregular, as the project was last fitted.
What the fit left freeA parameter gets an error when it is not fixed and its lower limit is below its upper limit.
The limitsTaken as they are. To change them, change them in X-Ray Calc 3, fit and save.

In a periodic fit the period of a stack gets an error even when the fit held it, as long as at least one thickness in the stack is free. The period is then allowed to move by 2 % either way.

The substrate is not analysed.

The list

The list has a Summary group and one group per stack.

  • Summary: for each repeating stack, the period (or the mean period), the total thickness, and the drift of the period from the first period to the last. A number that cannot move in this fit, such as the drift of a periodic stack, is shown without an error.
  • The stacks: each layer value that has one number for the whole stack: thickness H, roughness σ, density ρ.

The ± column is the error: the parameter lies inside value ± error in about two cases out of three. When the two sides differ much, both are shown, like +0.30 / −0.10.

Digits in the error (1 to 4, next to the buttons below) sets how many digits the error is shown with; the value is shown to the same decimal place. Copy table and Export give what is shown.

A layer value that changes from period to period (a profile or a table) has no row. It is drawn on the Depth chart, and the Summary numbers describe the stack as a whole.

Known values

If a number is known from another measurement, enter it: click the Known cell of its row, type the value, press Enter, then type its error in the next ± cell. Note is for where the number came from. To take a known value away, clear its Known cell.

Example: a profilometer gives the total thickness of the coating as 2790 ± 10 Å. Enter 2790 and 10 on the Total thickness row and run again. The errors of the other parameters usually become smaller.

Use a decimal point, not a comma. A known value can be entered on the Summary rows and on the rows of the stacks.

After a known value is changed the stored result is out of date; run again.

The charts

  • Curve: the measured points, the calculated curve (red) and its error range (the two thin lines), named in the legend under the chart. The thin lines should enclose the red one closely and follow the points.
  • Depth (profile and irregular fits only): a layer value against the period number, with its range. Choose the layer value in the box above the chart.

Warnings

Lines appear under the list only when there is something to say.

LineWhat it means and what to do
The model misses the measured curve by about ... %The calculated curve is further from the measurement than the noise of the measurement explains. The errors are wide because of that, or the run does not settle at all. Improve the model in X-Ray Calc 3 (a layer, an interlayer or a limit that is missing), fit, save, and run again.
No raw counts were foundThe errors are based on the scatter of the curve alone. They are more reliable when the tool can read the detector counts: keep the .xrdml file the curve was loaded from where it was, and do not trim or smooth the curve.
... sits at its limitThe parameter wants to go beyond its limit, so its error is cut off there. Widen the limit in X-Ray Calc 3, fit again, save. For a period that the fit held, the limit is the tool's own 2 %: fit with Free period on instead.
The graphics card stopped; the run finished on the processorThe result is as good as any other; the run only took longer.
The run failed: ...Something went wrong inside the calculation and nothing was changed. Run again; if it repeats, report the project.
... the result repeats what was entered as knownThe measurement says nothing more about this parameter than the known value already did.
The fit has not settledNo errors are given, because they could not be trusted. Refit the model in X-Ray Calc 3 (more iterations, or a better start) and try again. If the line goes on to say that the model misses the curve, that is the likely reason.
The model, the curve or the known values have changed since this result was madeThe numbers shown belong to an earlier state of the project. Run again.
The model has ... per-period table values freeAn irregular fit with more than 20 free table values cannot be analysed. Fit it with a profile, or pair or fix some of the values.
Nothing in the model is free to varyEvery value is fixed or has equal limits. Free the parameters of interest in X-Ray Calc 3, fit and save.
The result is shown here onlyThe project file could not be written (read-only, or in use). The result stays on the screen: use Copy table or Export.
The project holds uncertainties stored by another version of this toolThey cannot be shown by this version. Running again replaces them.

Details, Copy table, Export

  • Details...: how the run went, the scale, background and noise of the measurement, how well the run agrees with itself for each parameter, and which parameters move together. Two parameters that move together cannot be told apart well by this measurement.
  • Copy table: the list as text, to paste into a spreadsheet or a report.
  • Export...: the list as a CSV file.
  • Clear...: removes everything the tool stored in the project file: the uncertainties, the known values and the stored counts. The model and the curve are not changed. Use it on a project saved under a new name that should not carry the earlier result. If the project is open in X-Ray Calc 3, saving it there afterwards does not bring the removed data back.

What it does not do

  • It does not change the model, the limits or the fit.
  • It analyses one curve at a time. Several curves fitted together are not supported.
  • It works on angle scans only.
