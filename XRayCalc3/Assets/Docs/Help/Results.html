Saving Results

Result > Export ... saves the active model's calculated curve to a text file (.dat) with two tab-separated columns. The header names them: the x column after the chart axis (2Theta or Theta, in deg, or Wavelength, in Å), the second Reflectivity.

Copying to Clipboard

  • Result > Copy to clipboard — copy reflectivity data as tab-separated text, with the same column names as the export
  • Result > Copy as BMP — copy the chart as a bitmap image
  • Result > Copy as EMF — copy the chart as an enhanced metafile (vector format, suitable for publications)

Saving the Plot

Result > Save as graphics ... saves the chart as an image file: BMP, EMF (enhanced metafile) or WMF, chosen by the file type in the dialog. The file gets that type's extension; an extension typed in the name is replaced.

Structure Image

Structure > Copy as image copies the visual structure diagram (the layer/stack representation) to the clipboard as an image.

Fit Report v3.9.4

Result > Fit report ... answers "is this fit any good?" with the numbers the MCP server's fit_xrr report gives, for the active model against the measured curve linked to it. It is to a fit what Data > Assess XRR quality is to a measurement. Calculate the model first: the report reads its curve on the chart, over the range of the data. The window shows values only, with no pass or fail marks; what a good fit looks like is the fitting procedure's to say.

The measured curve is taken at the solved scale of the last calculation, the scale its χ² and the Chart Info bar show (Solving the Measured Scale); the header line gives the factor. Angles are in the chart's unit, 2θ or θ. The calculated curve is read at the measured angles (interpolated in log R between its own points).

  • Bragg orders: for every order of the first repeating stack's period inside the data, the measured and the calculated maximum in the order's window, each with its own angle, their ratio calc/meas, and whether the measured one stands more than three times above the background (the median of the last 100 points).
  • Critical edge: three points between the start of the data and the first minimum of the calculated curve, measured, calculated and their ratio. A minimum counts only once the curve rises 5 % above it, the rule the fringe count uses, so a small wiggle on the plateau between two critical angles is not taken for the foot of the edge (before 3.9.4.1050 any local minimum was).
  • Fringes between orders 1 and 2: the number of fringe pairs (a maximum and the minimum after it) and their mean contrast, measured and calculated.
  • Residual by band: the data range in eight equal bands of angle, each with its number of points and the mean and rms of log10(Rcalc/Imeas): where the model sits above the data (positive) and where below, in decades.
  • Parameters within 5 % of a bound: every free layer parameter that sits within 5 % of its range of Min or Max in the current limits, as the Fitting Limits dialog flags them.

Copy as text puts every table on the clipboard, tab-separated.

Auto-Save Results

When enabled in Settings (Automatically save results to output folder after fitting), the whole project is saved as <project>-fitted.xrcx in the Fitting Output folder, or next to the project when that setting is blank (a project that was never saved goes to the Default Project's Folder). The folder is created if it is missing. The save happens when a fit ends; with Live update structure panel during fitting also on, it also happens during the fit, whenever the chart is updated with a better χ². The project's own .xrcx file is not touched.

Exporting Fit Results

Result > Export fit results... writes the project's fit record to a JSON file. Since the version after 3.9.4.1130 the record is taken when a fit ends and saved with the project (the [FITRESULT] section of params.dsc), so the export works after the project is reopened and describes the fit as it ran, whatever has been changed since. It holds:

  • the program version and platform, fitDate, fittingSeconds, fittingDevice, the seed, whether the fit was a resume, the fittingMode (and, in Irregular mode, startFromTables), the model and the dataItem it was fitted to;
  • chiSquared (the engine's best, the number minimised), chiSquaredRecalc and chiSquaredPlain (the model it ended on, weighted and unweighted), chi2Scale, scaleRatio, scaleClamped;
  • chi2Weighting (theta weight, point weight, moving-average window) and rMin;
  • fitParams: every fitting setting, with polyOrder/polyFactor in Polynomial mode and smooth/smoothWindow in Irregular mode;
  • calcParams: the range in θ (startTheta, endTheta, deltaTheta — the resolution, formerly exported as step), the wavelength, the number of points, polarisation, roughness function, and whether the chart shows 2θ;
  • structure: every layer's thickness, roughness and density with their limits and the paired and frozen flags, and a perPeriod list where an Irregular fit gave the layer a value per period;
  • polynomials in Polynomial mode: the coefficients of every depth profile.

A project with no fit record says so and writes nothing.
