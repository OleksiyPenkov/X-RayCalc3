Algorithm

XRC3 uses the exact Parratt recursion for specular X-ray reflectivity. The medium above the structure is vacuum (ε = 1) and the substrate is semi-infinite. The dielectric constant of each layer is ε = 1 − 2δ + 2iβ, with δ and β proportional to ρλ²f1/A and ρλ²f2/A (ρ the density, A the molar mass). The atomic scattering factors f1, f2 come from the Henke tables (Henke et al., 1993), linearly interpolated in photon energy, E = 12398.6/λ eV (λ in Å).

Interface roughness is Gaussian. The Fresnel coefficient of every interface is multiplied by a Névot–Croce-type factor exp(−q0q′σ²/2), where q0 = 4π sinθ/λ is the wave-vector transfer in vacuum and q′ the one refracted across the interface; the same factor is applied to s and p. The σ of a layer is the roughness of its upper interface (see Layers).

Reflectivity can be calculated as a function of either the grazing angle or the wavelength. Calculated values below the chart's minimum-limit setting (the reflectivity floor in the Chart Info bar, default 10−7) are raised to it; the floor applies to the χ² too.

Calculation Modes

X-Ray Calc 3 supports two calculation modes:

Theta Mode (by angle)

Calculates reflectivity as a function of the grazing angle (measured from the surface) at a fixed wavelength.

ParameterDescription
θ1Start angle (degrees)
θ2End angle (degrees). The calculated points are θ1 + i·(θ2 − θ1)/N, so θ2 itself is not calculated.
λ (Å)Fixed wavelength in Angstroms (default: 1.54043 Å, close to Cu Kα1, 1.5406 Å)
ΔθInstrumental angular resolution: the FWHM, in degrees θ, of the Gaussian the calculated curve is convolved with (default 0.015; 0 = no convolution). It is not the step. The Gaussian is cut off at ±0.1° on the chart axis, so a resolution wider than about 0.08° (0.04° with 2θ ticked) is under-represented.
2θWhen checked, θ1, θ2 and the chart axis are in 2θ (the calculation divides by 2). Δθ is always entered in θ.
Convolution edges: the convolution needs 0.1° of curve on each side of a point. The first points of the curve (0.1° worth) are left unconvolved and the last ones are replaced by a short trailing moving average; the χ² leaves out these end points (see Understanding the Cost Function). The convolution assumes evenly spaced points.

Lambda Mode (by wavelength)

Calculates reflectivity as a function of wavelength at a fixed grazing angle.

ParameterDescription
λ1Start wavelength (Angstroms)
λ2End wavelength (Angstroms). The step is (λ2 − λ1)/N.
θFixed grazing angle in degrees, measured from the surface (90° = normal incidence; default 85°). The 2θ box does not apply here.
ΔλSpectral resolution: the FWHM (Å) of the Gaussian the curve is convolved with (default 0 = none; cut off at ±0.1 Å). It is not the step.
Lambda mode reads the atomic scattering factors f1, f2 at every wavelength of the scan, so the energy dependence of δ and β, absorption edges included, is followed; a function (gradient) profile counts its periods from the surface at every wavelength. (Before 3.9.3 f1, f2 were read once, at λ1, and a profile off the top layer was mis-indexed after the first wavelength.) Lambda mode runs on a single thread.

Polarization

  • s-type: S-polarization (TE mode, electric field perpendicular to the plane of incidence)
  • sp-type: unpolarized beam, R = (Rs + Rp)/2, with the same roughness factor applied to both components
Guidance: What decides is the grazing angle, not the photon energy. Away from the critical angle Rp ≈ Rs cos²2θ, so sp is lower than s by the fraction (1 − cos²2θ)/2: under 0.5 % below θ ≈ 3°, about 1.5 % at 5°, 6 % at 10° and 20 % at 20°. Use s-polarization at small grazing angles, where the difference is negligible and the calculation is faster. Use sp-polarization for an unpolarized source at larger angles, for example near-normal EUV and soft X-ray geometries; Rp falls to nearly zero near the Brewster angle, θ ≈ 45°.

Number of Points (N)

The N parameter sets the number of calculated points (default 2000 in a new session; a project that stores none opens with 1000). More points give smoother curves but take longer to compute. In Theta mode N is rounded down to a multiple of the number of threads.

When a measured curve is linked to the model and the model curve is visible, N is not used: the model is calculated at the measured angles.

Running a Calculation

  1. Select a model in the project tree.
  2. Set the calculation parameters (mode, angle/wavelength range, polarization, N).
  3. Choose Calc > Calculate or click the Calc Run toolbar button.
  4. The calculated reflectivity curve appears on the main chart.

When a measured curve is linked, Calculate also reports the χ² against it, and the plain χ², in the Chart Info bar, at the scale shown in the scale pane (see Understanding the Cost Function and Solving the Measured Scale).

Calculate All (Calc > Calculate All) calculates reflectivity for every model in the project.

Auto-Calculation

Auto-Calc: When enabled in Settings, the reflectivity is recalculated automatically whenever you modify the structure. This provides real-time feedback as you adjust layer parameters.

Multi-Threading

In Theta mode the calculated points are divided into as many contiguous segments as there are threads, and the segments are computed in parallel (with a linked measured curve, its points are divided the same way). Lambda mode runs on a single thread. Configure the number of threads in File > Settings > Calc & Fit:

  • Auto (Use all) — one thread per logical processor available to the process (default)
  • 2, 4, 8, 12, 16, 32, 64 — limit to a specific number of threads
Performance: With a 16-core CPU, the typical simulation time for XRR ranges from 0.05 to 0.25 s for a periodic multilayer model consisting of 300 stacks of 4 layers each (3000-point curve). This speed enables real-time manual curve fitting.
