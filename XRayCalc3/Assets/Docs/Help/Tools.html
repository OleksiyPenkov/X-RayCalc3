Create new material

Tools > Create new material ... opens a dialog to add a custom material to the Henke database.

Choose the number of components, pick each one (an element or an existing material) and give its concentration in atomic per cent, then a name and a density (g/cm³). The program writes Henke\<Name>.bin with f1, f2 and the molar mass averaged per atom with the atomic fractions, f = Σ cifi, on the energy grid of the first component (the others are interpolated onto it). The density you enter becomes the bulk density used when a layer's density is 0.

Note: the percentages must add up to 100 at.%; the dialog refuses to save otherwise, and asks before replacing an existing material of the same name.

Edit Henke Table

Tools > Edit Henke Table opens the Henke Table Editor, which allows you to view and modify the atomic scattering factor tables used for reflectivity calculations.

A Henke table holds the atomic scattering factors f1 and f2 of one material against photon energy E (the λ column is 12398.6 / E, in Å), together with the molar mass and the bulk density. The optical constants δ and β are proportional to (ρ / A) λ² f1 and (ρ / A) λ² f2. The f1 and f2 cells, the molar mass and the density can be edited; Save overwrites the file. A value shown as N/A is not tabulated.

Note: f1, f2 and the molar mass are per formula unit and enter the optical constants as a ratio. Change the mass only together with f1 and f2, or every layer of that material changes its optical constants.

Benchmark

Calc > Benchmark measures how reliably the optimizer converges, not how fast it runs:

  • Every project (.xrcx) in the Benchmark folder is reopened and fitted N times, with the fit settings stored in it.
  • The final χ² of each run is tabulated with statistics, and the table is saved to BenchResults\benchmark-<date>.dat.
  • A spread of final χ² values shows how often the swarm finds the same minimum; compare optimizer settings this way.

Configure the number of runs N (default 20) in File > Settings > Calc & Fit. For the time a fit takes, see the fitting time in the status bar.
