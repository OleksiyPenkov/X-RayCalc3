Project File (.xrcx)

A ZIP archive of the project's working folder:

  • project.dsc — the project tree (binary): every model's structure (stacks, layers, substrate) as JSON, the titles and descriptions of the data items, and the profile extensions with their coefficients.
  • params.dsc — an INI file with the calculation and fitting settings, no layers: [PARAMS] (N, mode, polarisation, chart minimum), [ANGLE] and [WAVE] (ranges, wavelength, resolution, the 2θ switch), [FIT] and [LFPSO] (fit settings, including SolveScale and ScaleWindow), [INFO] Version, and [STATE] (linked data, active model, log scale).
  • data_<ID>.dat — one text file per data item, in the clipboard layout (three header lines, then angle and reflectivity).
  • calc.dat — the active model's calculated curve.

Data curves are stored with the angle rounded to 0.001° and the reflectivity to five significant digits; Load, Normalize, Smooth and Trim all write through this, so a finer angle step than 0.001° is rounded and can produce repeated angles.

The current project version is 8. A project of version 7 or earlier opens with the substrate density reset to 0 (bulk), because earlier versions ignored the substrate density.

Experimental Data Files

Plain text, one point per line: angle (or wavelength), a single TAB, reflectivity:

* Optional description lines starting with *
0.100	1.000000
0.200	0.999850
...

Column 1: the angle in degrees, 2θ when the calculation's 2θ switch is on and θ when it is off (a text file is not converted), or the wavelength in Å in wavelength mode.
Column 2: reflectivity.

Use exactly one separator (one TAB, or one space in a file without TABs) and no third column; both numbers must start with a digit. Other lines are skipped. The full rules are in Experimental Data > Data Format.

XRDML (PANalytical)

A PANalytical / Malvern .xrdml file, schema 1.0 to 2.x, is read without conversion by Data > Load and by the MCP server's inbox. What is read:

  • the first scan of the file that has data points, its 2Theta positions (start/end, a position list, or Omega for a rocking curve; a file whose 2θ does not move and has no Omega positions is refused);
  • counts (raw, with beamAttenuationFactors multiplied in when present) or intensities (already corrected), divided by commonCountingTime or the per-point countingTimes (left undivided when the file has neither);
  • the wavelength: Kα1 and Kα2 with their ratio, weighted together unless a monochromator or a hybrid mirror is in the incident path;
  • the detector name and read-out period, the sample id, the scan status and start time.

The curve is normalised to 1 at its maximum. A zero or negative count is replaced by the smallest positive rate before it (1000 counts/s when none precedes it); a text file is floored the same way. The peak count rate of the corrected curve is kept in the description. See Experimental Data > Loading XRDML Files.

Henke Tables

One binary file per material, element or compound, Henke\<Name>.bin (the Henke folder beside the program, or under the storage folder set in Settings). A layer's material name must match a file name. Each file holds:

  • the material name, the molar mass A (g/mol, per formula unit) and the bulk density (g/cm³);
  • records of (photon energy E in eV, f1, f2) on an energy grid. The wavelength is λ = 12398.6 / E (Å); f1 and f2 are interpolated linearly in E.

The optical constants follow from these: δ and β are proportional to (ρ / A) λ² f1 and (ρ / A) λ² f2, with ρ the layer's density, or the bulk density from the file when the layer's is 0. For a compound, f1, f2 and A are all per formula unit, so they must be changed together (see Edit Henke Table). The tables are included with the application.

Settings File (xrc3.ini)

A standard Windows INI file, %APPDATA%\X-RayCalc3\xrc3.ini, or next to the program when a file named uselocaldata sits there. Sections:

  • [Path] — the Henke, storage, benchmark, project, output and jobs folders
  • [Window] — window state, position and size
  • [Options] — CheckForUpdates, UpdateInfoURL, AutoCalc, AutoSave, LiveUpdate
  • [Graphics] — LineWidth
  • [Calc] — NumberOfThreads (0 = all), BenchmarkRuns (20), UseGPU (on). The calculation parameters themselves (range, wavelength, resolution, fit settings) are stored in each project's params.dsc, not here.
  • [Recent] — the recent-projects list
