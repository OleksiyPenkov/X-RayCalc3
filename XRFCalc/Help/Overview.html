Application Overview

Window layout, the run configuration panel, toolbar, tab panels, and menus
On this page

  • Menus

XRFCalc is a standalone viewer and runner for Universal Mirror optimization results. It is separate from the main X-Ray Calc 3 application. Its purpose is to browse .xrfx result files, inspect their reflectivity curves and structure parameters, and launch new optimization runs via the xrccmd backend.

Window Layout

The main window is divided into two regions separated by a vertical splitter:

+---------------------------+------------------------------------------+ | Run Configuration | Results Panel (tabbed) | | | | | [Targets | Structure | | [ Curves | Info | Progress ] | | Optimizer | Fitness] | | | | (selected tab content fills this area) | | | | +---------------------------+------------------------------------------+

Drag the splitter between the two regions to adjust their relative widths. The layout is remembered between sessions.

Run Configuration Panel

The left panel contains the run configuration organized into four tabs:

  • Targets — select target XRF lines, configure the element pool, and manage excluded material pairs.
  • Structure — set period thickness range, gamma range, number of periods, roughness, density factor, substrate, and pure-elements mode.
  • Optimizer — configure population size, iterations, stagnation limit, PSO weights, tolerance, jamming, and checkpoint intervals.
  • Fitness — set figure-of-merit weights (w_R, w_FWHM, w_purity), polarization mode, angular resolution, scan parameters, and Henke database path.

The configuration panel is always visible. When you load an .xrfx file, its stored configuration is loaded into these tabs. To start a new optimization, adjust the settings and click New Run in the toolbar.

Opening files: Use File > Open (Ctrl+O) or the Open toolbar button to load a .xrfx result file. You can also register the file association (Tools > Register .xrfx Extension) so that double-clicking a .xrfx file in Windows Explorer opens it directly in XRFCalc. See File Association.

Toolbar

The toolbar at the top of the window provides quick access to the most common actions:

ButtonActionNotes
OpenOpen a .xrfx fileLoads a result file and populates the Curves, Info, and Progress tabs. The run configuration panel is updated with the stored settings.
Export StructureExport the mirror structureSaves the best-structure definition from the current .xrfx file for use in other tools.
Copy DataCopy curve data to clipboardCopies the currently displayed reflectivity data as tab-separated text, ready to paste into a spreadsheet.
Save ImageSave chart as PNGSaves a bitmap snapshot of the active chart (Curves or Progress) to a file.
New RunStart a new optimizationBuilds a configuration from the current settings in the left panel and launches xrccmd in the background.
StopCancel the running optimizationOnly visible while an optimization is in progress. Sends a stop signal to xrccmd.

Tab Panels

The right panel contains three tabs. Click a tab header to switch between views:

TabContent
CurvesMain results view: reflectivity chart, structure overlay, legend, and metrics bar charts. This is the primary tab for analyzing optimization results.
InfoText summary of the result file contents: figure of merit, structure parameters, target lines, element pool, optimizer settings, and per-element results.
ProgressLive convergence chart and console log. Active during a running optimization; shows historical data for completed runs loaded from file.

Menus

File Menu

ItemShortcutDescription
OpenCtrl+OOpen a .xrfx result file. The run configuration panel is updated with the stored settings.
SaveCtrl+SSave the current .xrfx file to its existing path. Used to persist results that were generated by a new run (which are initially stored in a temporary location).
Save AsCtrl+Shift+SSave the current .xrfx file to a new location chosen via a file dialog.
Save Config—Export the current run configuration panel settings as a standalone JSON file, for use with xrccmd or for sharing.

Tools Menu

ItemDescription
Template File...Select a template JSON file that defines multilayer structure patterns (material pair definitions with thickness ratios). This is a global application setting, persisted between sessions.
XRF Lines File...Select the xrf_lines.json file containing characteristic X-ray emission wavelengths. This is a global application setting and must be configured before running optimizations.
Register .xrfx ExtensionAssociates the .xrfx file extension with XRFCalc in the Windows registry. After registration, double-clicking a .xrfx file in Explorer opens it in XRFCalc.
