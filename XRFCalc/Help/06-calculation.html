6 Calculation Engine

XRFCalc uses the same reflectivity engine as the main X-Ray Calc 3 application. This chapter describes the physics and algorithms behind the optimization.

Parratt Recursive Method

Specular X-ray reflectivity is calculated using Parratt’s exact recursive method based on the Fresnel equations. For a multilayer structure with N layers, the reflectivity is computed by propagating the reflected amplitude from the substrate upward through each interface.

At each interface between layers j and j+1, the Fresnel reflection coefficient is:

rj,j+1 = (kz,j − kz,j+1) / (kz,j + kz,j+1)

where kz,j is the z-component of the wave vector in layer j, determined by the refractive index and incidence angle.

Interface Roughness

Interface roughness is incorporated via a Gaussian distribution using the Névot-Croce factor:

r′j,j+1 = rj,j+1 × exp(−2 kz,j kz,j+1 σj²)

where σj is the RMS roughness at interface j in Ångströms.

Polarization

The optimizer supports two polarization modes:

  • s-polarization — electric field perpendicular to the plane of incidence (TE mode)
  • sp-polarization — average of s- and p-polarization. Recommended for most applications, especially at soft X-ray wavelengths and larger angles where both components contribute significantly.

Validation

The computational algorithm has been validated against the IMD software (Windt, 1998), with accumulated variances consistently below 0.5%.

Henke Database

Refractive indices of materials are computed using the Henke tables of atomic scattering factors (Henke et al., 1993). The database provides the complex atomic scattering factor f = f1 + if2 for all elements from H to U, covering the photon energy range 10 eV to 30 keV.

The complex refractive index of a material is:

n = 1 − δ + iβ

where δ and β are calculated from the scattering factors and the material density. The Henke data files (.bin) are stored in the Henke/ directory next to the executable.

Virtual Crystal Approximation (VCA)

The Universal Mirror optimizer uses the Virtual Crystal Approximation to model mixed-material layers. Each layer’s composition is defined as a weighted mixture of elements from the user-defined pool (e.g. W, Si, C). The dielectric constant of the mixed material is computed as a weighted average of the constituents’ optical constants:

εmix = Σi wi εi

where wi are the normalized weight fractions and εi are the dielectric constants of individual elements from the Henke database.

When pure_elements is enabled in the configuration, each layer is forced to use a single material from the pool (the dominant component). This is recommended for most practical applications as it produces physically realizable structures.

LFPSO Algorithm

The optimizer uses Lévy Flight Particle Swarm Optimization (LFPSO) with the Shake modification — a population-based global optimization method designed for multimodal search spaces.

Particle Swarm Optimization

A population of candidate solutions (particles) moves through the search space. Each particle maintains:

  • Position — the current candidate solution (composition, d, γ, N, σ)
  • Velocity — the search direction and step size
  • Personal best — the best solution this particle has found
  • Global best — the best solution found by any particle

At each iteration, particle velocities are updated based on attraction toward their personal best and the global best, then positions are updated.

Lévy Flight

Lévy flights augment PSO with heavy-tailed random walks. The Lévy distribution produces mostly small steps (local search) with occasional large jumps (global exploration). This combination efficiently explores the search space and helps avoid local minima.

Shake Mechanism

When the optimizer stagnates (no improvement for stagnation_limit iterations), the Shake mechanism re-initializes the population around the current best solution. This helps escape local minima by introducing controlled randomization of positions and velocities.

Convergence Enhancements

The optimizer includes several improvements to the standard LFPSO:

EnhancementDescription
Reflective boundaries Particles bounce off search-space walls with 0.5× velocity damping instead of being clamped, keeping them active.
Adaptive Lévy scale Step size decreases from 0.10 to 0.01 over iterations — broad exploration early, fine-tuning late.
Adaptive PSO/Lévy switching Early iterations favor Lévy flights (70%) for exploration; later iterations favor PSO (70%) for exploitation. Stagnation temporarily boosts Lévy probability.
Random-peer Lévy targets 30% of flights target a random peer particle instead of the global best, creating diverse search directions.
Diversity-aware shake Shake checks population diversity before triggering. If particles are still spread out (≥ 1% of ranges), the shake is delayed to let ongoing exploration proceed.

Multi-Threading

Fitness evaluation is parallelized across all available CPU cores. Each particle’s reflectivity calculation runs independently, providing near-linear speedup with core count.

Figure of Merit

The figure of merit (FoM) combines peak reflectivity and angular bandwidth for all target wavelengths. Higher FoM is better.

FoM = Σi [ weighti × ( wR × Reff,i − wFWHM × FWHMi / FWHMref,i ) ]

where:

  • Reff,i — effective reflectivity for target i (purity-adjusted when w_purity > 0)
  • Rpeak,i — peak reflectivity (0–1), extracted from a scan around the Bragg angle
  • FWHMi — angular full width at half maximum (degrees) of the Bragg peak
  • FWHMref,i — theoretical minimum FWHM = λ / (N·d·cosθB), converted to degrees
  • weighti — per-target weight from the configuration
  • wR, wFWHM — global weights for reflectivity and bandwidth terms

Particles with Rpeak below R_min_threshold for any target receive a heavy penalty (100.0 per dark target) to steer the swarm toward functional solutions.

Spectral Purity

When optimizing for multiple wavelengths, higher-order Bragg reflections can cause cross-contamination between measurement channels. For example, a mirror tuned to O Kα (23.6 Å) at its first-order angle will also reflect λ/2 = 11.8 Å via the second order — nearly coinciding with Na Kα (11.9 Å).

Cross-Reflectivity Matrix

For each pair of targets i and j, the optimizer computes:

CrossR[j, i] = R(θj, λi)

This is the reflectivity of wavelength λi at the Bragg angle of target j. All Bragg orders are naturally included in the full multilayer calculation.

Purity and Effective Reflectivity

Purityj = Rpeak,j / ( Rpeak,j + Σi≠j CrossR[j, i] )
Reff,j = Rpeak,j × ( 1 + wpurity × ( Purityj − 1 ) )

When w_purity = 0, no penalty is applied. When w_purity = 1, Reff = Rpeak × Purity gives maximum penalization of contaminated channels.

Physical Factors

  • γ (layer ratio) — controls order suppression. γ = 0.5 eliminates all even-order reflections. Values far from 0.5 produce strong even-order peaks.
  • σ (roughness) — attenuates higher orders via the Debye-Waller factor, which decays exponentially with order number.
Tip: For large element pools with many close-spaced wavelengths, use w_purity = 1.0 and a population ≥ 500 to give the optimizer enough room to find purity-optimized solutions.
