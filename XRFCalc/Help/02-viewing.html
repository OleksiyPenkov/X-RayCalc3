2 Viewing Results

When you open a .xrfx file (File > Open or Ctrl+O), XRFCalc loads and displays its contents across three tabs. The Curves tab is the primary analysis view; Info gives a text summary; Progress shows convergence history. The loaded file name is shown in the window title bar.

Curves Tab

The Curves tab shows the reflectivity results for the best-found mirror structure. It is divided vertically into two areas:

  • Upper area — the main reflectivity chart and the legend panel.
  • Lower area — the structure overlay panel (left) and the metrics bar charts (right). A horizontal splitter between upper and lower areas can be dragged to resize them.

Chart Controls

The main reflectivity chart plots incidence angle (θ, degrees) on the X axis and reflectivity on the Y axis. Each target element is shown as a separate curve.

Scale Toggle

A toggle button above the chart switches the Y axis between logarithmic and linear scale:

  • Log scale (default) — suitable for inspecting the full dynamic range of the Bragg peak. Weak side-lobes and background reflectivity are visible.
  • Linear scale — useful when comparing peak heights directly.

Minimum Limit Selector

A drop-down next to the scale toggle sets the lower Y-axis limit in log scale (e.g. 10−6, 10−5, 10−4). This prevents the chart from extending into numerical noise for very low reflectivity values. Adjust it if the Bragg peak appears compressed at the top of the chart.

Zoom and Pan

The chart supports standard TChart interactions:

  • Left-drag — zoom into a rectangular region.
  • Right-click — context menu with options including Zoom Out, Zoom to Full, and Copy to Clipboard.
  • Mouse wheel — zoom in/out on the X axis centered on the cursor.

Legend

A floating legend panel sits horizontally above the structure overlay. It shows one entry per target element, each with a colored swatch and element name.

Each legend entry has a checkbox. Unchecking an element hides its curve in the main chart without removing the data. This is useful when you want to isolate a single element's curve in a multi-target result.

Tip: If curves overlap heavily in the same angular range, hide all but one element at a time to inspect individual Bragg peaks clearly.

Structure Overlay

The structure overlay panel displays the best mirror structure found by the optimizer as a table of layers. For a bilayer mirror, it shows two rows per period plus the substrate:

ColumnDescription
LayerLayer identifier (e.g. Layer 1, Layer 2, Substrate)
MaterialElement or composition of the layer (e.g. C, W 32.7% Si 35.8% C 31.5%)
d (Å)Layer thickness in Ångströms. For a bilayer, Layer 1 thickness = d × γ, Layer 2 = d × (1 − γ).
σ (Å)Interface roughness in Ångströms (shared across all interfaces).
DensityDensity factor relative to bulk. 1.0 = bulk density.

The global structure parameters (period d, gamma, N) are shown above the table as a summary line.

Metrics Charts

To the right of the structure overlay, four compact bar charts show per-element performance metrics for the best structure:

ChartDescription
Peak Position (θB)Bragg angle in degrees for each target element. Confirms the mirror reflects at a practical angle (> 3° is typically required).
R (Peak Reflectivity)Peak reflectivity (0–1) for each target. Higher is better.
FWHMAngular full width at half maximum of the Bragg peak in degrees. Narrower peaks give better spectral selectivity; broader peaks tolerate more angular divergence.
SNR (Spectral Purity)Signal-to-noise ratio related to spectral purity. A high value means low contamination from other-order reflections at this element's measurement angle.

Each bar is labeled with its numeric value. The bar color corresponds to the element's color in the legend and curves chart.

Info Tab

The Info tab shows a read-only text summary of everything stored in the .xrfx file. It is organized in sections:

  • Figure of Merit — the final FoM value achieved by the optimizer.
  • Structure Parameters — period d, gamma, N, sigma, and density factors for each layer.
  • Layer Compositions — element fractions for each layer.
  • Target Lines — the target elements, wavelengths, and weights specified in the run configuration.
  • Element Pool — the materials made available to the optimizer.
  • Optimizer Settings — population size, iteration count, stagnation limit, and other LFPSO parameters.
  • Per-Element Results — Rpeak, FWHM, Bragg angle, and spectral purity for each target element.

The Info text can be selected and copied (Ctrl+A, Ctrl+C) for pasting into reports or lab notebooks.

Progress Tab

The Progress tab shows the optimization convergence history:

  • Convergence chart (top) — plots the best figure of merit (FoM) vs. iteration number. A rising curve indicates the optimizer is still finding improvements. A flat plateau indicates convergence or stagnation.
  • Console log (bottom) — the text output from xrccmd, including the per-iteration progress table (Iter, FoM, R per element, Div) and any checkpoint or shake events.

During an active optimization (started via New Run), both the chart and the console update in real time. When the run completes, XRFCalc automatically switches to the Curves tab to show the result. For a result loaded from a completed .xrfx file, the Progress tab shows the recorded history from that run.

Console log: The console log is scrollable. During a long run you can scroll up to review earlier iterations without affecting the live update at the bottom.
