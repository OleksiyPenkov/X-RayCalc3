F1Open this help (Help > Contents).
XRFCalc is primarily a pointer-driven tool. Most operations are performed via toolbar buttons and mouse interaction with the charts and configuration panel.

File Association

XRFCalc can register itself as the default handler for .xrfx files in Windows. Once registered, double-clicking any .xrfx file in Windows Explorer opens it in XRFCalc.

To register:

  1. Open XRFCalc.
  2. Click Tools > Register .xrfx Extension.
  3. If prompted by User Account Control, click Yes to allow the registry change.

To unregister: use Windows Settings > Apps > Default Apps, or manually remove the .xrfx entry from the Windows registry under HKEY_CLASSES_ROOT.

Administrative privileges: Registering a file association writes to HKEY_CLASSES_ROOT which requires administrator rights on most systems. If the operation fails silently, run XRFCalc as administrator (right-click the executable > Run as administrator) and try again.

.xrfx File Format

An .xrfx file is a JSON document that bundles all data from a completed optimization run into a single portable file. It contains:

SectionContents
configThe full JSON configuration used to produce this result (targets, element_pool, structure, fitness, optimizer, top-level fields). Sufficient to reproduce or continue the run.
resultThe best-found solution: FoM, structural parameters (d, gamma, N, sigma), layer compositions, density factors, and per-element metrics (Rpeak, FWHM, θB, purity).
curvesReflectivity curve data for each target element: arrays of [theta, reflectivity] pairs covering the scan range around each Bragg peak.
progressPer-iteration history: FoM, per-element R values, and population diversity. Used to populate the Progress tab convergence chart.
logThe full console output from xrccmd, displayed verbatim in the Progress tab console.

.xrfx files are plain UTF-8 JSON and can be opened in any text editor for inspection or scripted post-processing.

Output Files from xrccmd

In addition to the .xrfx file created by XRFCalc, the xrccmd optimizer writes the following files to the configured output_dir:

FileDescription
best_structure.jsonThe best mirror structure in XRC3-compatible JSON format. Contains the full genome and a structure definition importable into X-Ray Calc 3.
best_curves/<Element>.datTab-separated reflectivity curves (angle, reflectivity) for each target. One file per element. Compatible with Origin, gnuplot, and Python/matplotlib.
population.jsonThe top 10 solutions ranked by FoM. Useful for exploring design alternatives with different material combinations or period values.
checkpoint.jsonFull optimizer state for resuming an interrupted run. Use the resume_from field in the configuration to continue from this checkpoint.
progress.logPlain text log of per-iteration statistics (Iter, FoM, R per element, Div). Matches the console output shown in the Progress tab.

Troubleshooting

New Run does nothing

Verify that xrccmd.exe is present in the same directory as XRFCalc. The optimizer backend must be co-located with the GUI. If it is missing, copy it from the X-Ray Calc 3 installation or build it from source.

The optimization exits immediately with no output

This usually means the configuration JSON is invalid. Check:

  • The XRF Lines file is configured (Tools > XRF Lines File...).
  • All required fields are present (lines, element_pool, structure, optimizer).
  • Each element in element_pool has a corresponding .bin file in the Henke directory.
  • structure.d.min > λmax / 2 (Bragg condition satisfied for all targets).
  • The output_dir path is writable.

Check the console log in the Progress tab for error messages from xrccmd.

FoM stays near zero for many iterations

The optimizer cannot find structures with meaningful reflectivity. Possible causes:

  • Period range too narrow: ensure d.max is well above λ/2 for all targets, giving the optimizer room to find valid Bragg conditions.
  • theta_min too high: if fitness.theta_min is set above the natural Bragg angle for the given d range, all solutions are penalized. Reduce theta_min or increase d.max.
  • Element pool unsuitable: the selected materials may have very low contrast at the target wavelengths. Try adding elements with known good reflectivity (e.g. W or Mo for soft X-rays).
  • Population too small: increase population and re-run.

The Progress chart shows FoM converging but then the run stops early

The stagnation_limit has been reached: the global best FoM did not improve for that many consecutive iterations. This is normal behavior indicating convergence. If you believe there is room for improvement, increase stagnation_limit and iterations and resume from the checkpoint.

Saving fails with a path error

Use File > Save As to choose an explicit save path. Avoid paths with special characters. Ensure the target directory exists and is not write-protected.

File association does not work after registering

On Windows 10/11, file association changes may require signing out and back in, or may be overridden by another registered application. If the association is not applied, open Settings > Apps > Default Apps, scroll to .xrfx, and manually set XRFCalc as the default program.
