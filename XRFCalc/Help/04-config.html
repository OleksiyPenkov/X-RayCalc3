4 Configuration Reference

The Universal Mirror Optimizer is driven by a JSON configuration file. XRFCalc writes this file for you when you use the run configuration dialog, but you can also create or edit it manually. This chapter documents every field.

The top-level JSON object has six sections: targets, element_pool, structure, fitness, optimizer, and several top-level scalar fields.

targets

An array of characteristic X-ray lines to optimize for simultaneously. Each entry specifies one target:

"targets": [
  {"element": "C",  "lambda": 44.7, "weight": 1.0},
  {"element": "O",  "lambda": 23.6, "weight": 1.0}
]
FieldTypeRequiredDescription
elementstringYesElement symbol used for labeling output files and the progress table. Does not need to match a Henke database entry — it is a label only.
lambdanumberYesCharacteristic wavelength in Ångströms. Common values: C Kα = 44.7 Å, N Kα = 31.6 Å, O Kα = 23.6 Å, F Kα = 18.3 Å, Na Kα = 11.9 Å, Mg Kα = 9.89 Å.
weightnumberYesRelative weight of this target in the figure of merit. Use equal weights (1.0) for balanced optimization. Increase a weight to prioritize that element's reflectivity at the expense of others.
Number of targets: The optimizer works with any number of targets (≥ 1). With a single target it behaves as a conventional single-wavelength optimizer. With many targets (5+), increase the population size to compensate for the larger search space.

element_pool

An array of element symbols available for layer composition. The optimizer selects materials from this pool when constructing each layer:

"element_pool": ["W", "Si", "C"]

Each element listed must have a corresponding Henke atomic scattering factor file (.bin) in the Henke data directory (set by henke_path). The optimizer assigns composition fractions to each pool element for each layer. When pure_elements is true in the structure section, each layer is forced to use the dominant single element from the pool.

Pool size guidance: Pools of 3–5 elements work well with a population of 100. Each additional element adds composition dimensions per layer, so larger pools benefit from larger populations (200+). Avoid including elements with nearly identical optical constants at your target wavelengths — they add search dimensions without meaningful diversity.

structure

Defines the mirror topology and the search ranges for structural parameters:

"structure": {
  "type": "bilayer",
  "layers_per_period": 2,
  "pure_elements": true,
  "d":              {"min": 20, "max": 80},
  "gamma":          {"min": 0.2, "max": 0.8},
  "N":              {"min": 20, "max": 100},
  "sigma":          {"min": 0.5, "max": 3},
  "density_factor": {"min": 0.7, "max": 1.3}
}
FieldTypeDescription
typestringStructure topology. Currently only "bilayer" is supported (two layers per period: a reflector and a spacer).
layers_per_periodintegerMust be 2 for bilayer mode.
pure_elementsbooleanWhen true, each layer is forced to use a single material (the element with the highest composition fraction). Recommended for practical applications. When false, layers can be arbitrary mixtures of pool elements via the Virtual Crystal Approximation.
drangePeriod thickness search range in Å. The Bragg condition requires d > λ/2 for each target wavelength. Set dmin above the largest λ/2 in your target list. Example: for C Kα (44.7 Å) the minimum is d > 22.4 Å.
gammarangeRatio of Layer 1 thickness to the full period d (0–1). Layer 1 thickness = d × γ; Layer 2 = d × (1 − γ). γ also controls higher-order suppression: γ = 0.5 completely eliminates even Bragg orders.
NrangeNumber of bilayer periods. Evaluated as an integer (fractional values are rounded). More periods produce sharper, more intense Bragg peaks but tighter angular acceptance.
sigmarangeInterface roughness in Å, applied uniformly to all interfaces via the Debye-Waller damping factor. Typical thin-film roughness is 0.5–3 Å.
density_factorrangeDensity multiplier for each layer relative to bulk. 1.0 = bulk density. Values < 1.0 model porous or amorphous films; values > 1.0 model compressive stress. A single range applies to all layers.
Bragg condition check: For a target at wavelength λ, the Bragg condition is λ = 2d·sin(θB). The optimizer automatically penalizes structures where θB would fall below fitness.theta_min. Setting d.min appropriately avoids wasting population on infeasible solutions.

fitness

Controls how the figure of merit (FoM) is calculated from the reflectivity curves:

"fitness": {
  "w_R":             1.0,
  "w_FWHM":          0.3,
  "R_min_threshold": 0.0001,
  "polarization":    "sp",
  "delta_theta":     0.1,
  "theta_min":       3.0,
  "w_purity":        1.0,
  "scan_points":     200,
  "scan_half_range": 5.0
}
FieldTypeDefaultDescription
w_Rnumber1.0Weight for peak reflectivity in the FoM formula. Higher values drive the optimizer to maximize Rpeak.
w_FWHMnumber0.3Weight for the FWHM penalty. Penalizes broad Bragg peaks. Set to 0 to ignore bandwidth entirely and optimize only for peak reflectivity.
R_min_thresholdnumber0.0001Minimum acceptable peak reflectivity. Solutions with Rpeak below this value for any target receive a heavy penalty (100.0 per dark target), steering the swarm away from non-functional structures.
polarizationstring"sp"X-ray polarization mode. "sp" averages S and P polarizations (standard for most synchrotron and laboratory sources). The reflectivity calculation uses this mode for all fitness evaluations.
delta_thetanumber0.1Instrumental angular resolution in degrees. The calculated reflectivity curve is convolved with a Gaussian of this width before extracting Rpeak and FWHM. Set to the actual angular divergence of your measurement setup for physically meaningful results.
theta_minnumber3.0Minimum acceptable Bragg angle in degrees. Targets whose first-order Bragg angle would fall below this value receive a heavy penalty. Prevents solutions at impractically low grazing angles where the mirror cannot be physically mounted.
w_puritynumber1.0Spectral purity weight (0–1). Controls how strongly higher-order contamination between targets is penalized. 0 = no purity penalty; 1 = maximum penalty. See the FoM formula below.
scan_pointsinteger200Number of points in the reflectivity scan around each Bragg peak used for fitness evaluation and stored in output curve files.
scan_half_rangenumber5.0Half-range of the angular scan in degrees. The scan covers [θB − half_range, θB + half_range]. Increase this if you need to capture wide peaks or side-lobes in the output curves.

Figure of Merit Formula

The optimizer maximizes:

FoM = Σi [ weighti × ( wR × Reff,i − wFWHM × FWHMi / FWHMref,i ) ]

where Reff,i = Rpeak,i × Purityi when w_purity = 1, and Reff,i = Rpeak,i when w_purity = 0. FWHMref,i is the theoretical minimum bandwidth for the structure, used to normalize the FWHM penalty across different target wavelengths.

Spectral Purity

When optimizing for multiple wavelengths, higher-order Bragg reflections can contaminate measurement channels. For example, a mirror at the O Kα (23.6 Å) Bragg angle also reflects at λ/2 = 11.8 Å via the second order, which can overlap with Na Kα (11.9 Å).

Purity for target j is defined as:

Purityj = Rpeak,j / ( Rpeak,j + Σi≠j CrossR[j,i] )

where CrossR[j,i] is the reflectivity of wavelength λi at the Bragg angle of target j. Setting w_purity = 1.0 tells the optimizer to actively minimize this contamination.

When to use purity: Enable w_purity = 1.0 whenever your target elements have characteristic lines that are near integer multiples of each other (e.g. O at 23.6 and Mg at ~9.9 are not a problem, but O at 23.6 and Na at 11.9 are, since 23.6/2 ≈ 11.8). For single-target runs, purity has no effect and can be left at any value.

optimizer

LFPSO (Lévy Flight Particle Swarm Optimization) algorithm parameters:

"optimizer": {
  "population":       100,
  "iterations":       500,
  "tolerance":        1e-8,
  "stagnation_limit": 50,
  "w1":               0.4,
  "w2":               0.5,
  "jamming_max":      5,
  "checkpoint_every": 50
}
FieldTypeDefaultDescription
populationinteger—Number of particles (candidate solutions). Larger populations explore more broadly but increase computation time per iteration. Recommended: 100 for 3-element pools, 200+ for larger pools or more than 3 targets.
iterationsinteger—Maximum number of iterations. The optimizer may stop early if stagnation_limit is reached. For exploratory runs use 100–200; for production runs use 500–1000.
tolerancenumber1e-8FoM convergence threshold. Not actively used for early stopping in the current implementation; kept for forward compatibility.
stagnation_limitinteger50Number of iterations without improvement in the global best FoM before the optimizer declares convergence and stops. Set higher (100+) for complex search spaces with many local optima.
w1number0.4PSO inertia weight: the fraction of the previous velocity retained in each update. Lower values reduce momentum and tighten exploitation.
w2number0.5PSO inertia decay factor: reduces the effective inertia over iterations, transitioning from global exploration to local exploitation.
jamming_maxinteger5Number of iterations without improvement for an individual particle before it is considered jammed and a shake event is considered. Subject to the population diversity check — shaking is suppressed while the swarm is still diverse.
checkpoint_everyinteger50Save a full checkpoint (all particle positions, velocities, and personal bests) every N iterations. Set to 0 to disable periodic checkpoints. A final checkpoint is always saved when the optimizer exits.
Recommended starting point: population: 100, iterations: 500, stagnation_limit: 50 with default w1/w2 works well for most 2–3 target problems. Double the population if the FoM varies widely across restarts, indicating the search space is not being covered adequately.

Top-Level Fields

These scalar fields appear at the top level of the JSON object alongside the section objects:

"substrate":   "Si",
"henke_path":  null,
"output_dir":  "./results",
"resume_from": null,
"template_file": null
FieldTypeDescription
substratestringElement symbol of the substrate material. Used as the bottom layer of the mirror structure in reflectivity calculations. Common values: "Si", "SiO2", "Glass". Must have a Henke database entry.
henke_pathstring or nullPath to the directory containing Henke atomic scattering factor .bin files. null uses the default location next to the xrccmd executable (Henke/ subdirectory).
output_dirstringDirectory where all output files are written: best_structure.json, curve files in best_curves/, population.json, checkpoint.json, progress.log. Created automatically if it does not exist.
resume_fromstring or nullPath to a checkpoint file to resume an interrupted run. null starts fresh. When resuming, the population size and element_pool must match the checkpoint. The iterations count can be increased to allow more cycles.
template_filestring or nullOptional path to a template configuration file. When set, fields from the template are used as defaults for any fields not explicitly specified in the current configuration. Useful for standardizing fitness and optimizer settings across multiple runs.

Full Example

A complete configuration for a dual-target C Kα / O Kα mirror using W/Si/C materials:

{
  "targets": [
    {"element": "C", "lambda": 44.7, "weight": 1.0},
    {"element": "O", "lambda": 23.6, "weight": 1.0}
  ],
  "element_pool": ["W", "Si", "C"],
  "structure": {
    "type": "bilayer",
    "layers_per_period": 2,
    "pure_elements": true,
    "d":              {"min": 20, "max": 80},
    "gamma":          {"min": 0.2, "max": 0.8},
    "N":              {"min": 20, "max": 100},
    "sigma":          {"min": 0.5, "max": 3},
    "density_factor": {"min": 0.7, "max": 1.3}
  },
  "fitness": {
    "w_R":             1.0,
    "w_FWHM":          0.3,
    "R_min_threshold": 0.0001,
    "polarization":    "sp",
    "delta_theta":     0.1,
    "theta_min":       3.0,
    "w_purity":        1.0,
    "scan_points":     200,
    "scan_half_range": 5.0
  },
  "optimizer": {
    "population":       100,
    "iterations":       500,
    "tolerance":        1e-8,
    "stagnation_limit": 50,
    "w1":               0.4,
    "w2":               0.5,
    "jamming_max":      5,
    "checkpoint_every": 50
  },
  "substrate":     "Si",
  "henke_path":    null,
  "output_dir":    "./co_mirror_results",
  "resume_from":   null,
  "template_file": null
}
