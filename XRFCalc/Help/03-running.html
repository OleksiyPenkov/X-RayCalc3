3 Running Optimizations

XRFCalc launches the xrccmd command-line optimizer in the background and streams its output to the Progress tab. You can start a fresh run from scratch, or modify the configuration of an existing result and re-run it.

New Run

Click the New Run toolbar button to open the run configuration dialog with default (blank) settings.

The configuration dialog is organized into sections corresponding to the JSON configuration format:

  • Targets — add one or more target elements. For each target, enter the element name, characteristic wavelength (Å), and weight.
  • Element Pool — select which materials the optimizer may use for layer compositions (e.g. W, Si, C).
  • Structure — set the period thickness range, gamma range, number of periods range, roughness range, and density factor range.
  • Fitness — configure the figure of merit weights (w_R, w_FWHM), spectral purity weight, angular resolution, and minimum Bragg angle.
  • Optimizer — set population size, iteration count, stagnation limit, and checkpoint interval.
  • Output — choose the output directory for result files and optionally specify a resume checkpoint.

When you click OK in the dialog, XRFCalc writes a temporary JSON configuration file and launches xrccmd -u config.json in the background. The Progress tab becomes active and begins streaming output.

Quick start: For a first run, fill in the Targets and Element Pool sections and leave all other parameters at their defaults. The defaults are sensible starting points for most mirror design problems.

Edit Run

Click the Edit Run toolbar button to re-run the currently loaded .xrfx file with modifications.

XRFCalc reads the configuration stored inside the .xrfx file and pre-fills the configuration dialog with those settings. You can then:

  • Increase the iteration count to continue refining a good result.
  • Widen or narrow parameter search ranges based on what the first run found.
  • Adjust target weights to emphasize a different element.
  • Change the element pool to explore different material combinations.

After clicking OK, the run starts just like a New Run. The previous result file is not modified until you explicitly save the new result.

Resume vs. Edit Run: Edit Run always starts the optimizer from scratch with the modified configuration. To continue a run from where it left off (using a checkpoint), set the resume_from field in the configuration dialog's Output section to the path of the checkpoint file. See Optimizer settings and Top-Level Fields.

Live Monitoring

While an optimization is running, the Progress tab shows live output:

  • The convergence chart plots FoM vs. iteration. Watch for the curve flattening out, which signals that the optimizer has converged or is stuck.
  • The console log streams the per-iteration table from xrccmd, including:
    • Iter — current iteration number.
    • FoM — best figure of merit seen so far (higher is better).
    • R_X — peak reflectivity for each target element X.
    • Div — population diversity (0–1). Low values mean the swarm has converged. Shaking events may reset diversity briefly.

When the run completes, the Curves tab automatically updates to show the new best result, and the Info tab shows the final summary.

Reading diversity: If diversity reaches near zero early but FoM is still low, the optimizer has converged to a local optimum. Stop the run, widen the search ranges, and start again with a larger population.

Stopping a Run

Click the Stop toolbar button to cancel a running optimization. XRFCalc sends a stop signal to the xrccmd process. The optimizer saves a final checkpoint before exiting, so no progress is lost.

After stopping, the best result found so far is displayed in the Curves tab. You can save it as a .xrfx file and resume later if desired.

Do not close XRFCalc while an optimization is running without first clicking Stop. Closing the window while xrccmd is active will terminate the process without saving a checkpoint.

Saving Results

Results produced by a new run are stored in a temporary location. They are not automatically saved to a permanent .xrfx file. To keep results:

  • File > Save (Ctrl+S) — saves to the last-used save path. On the first save after a new run, this behaves like Save As.
  • File > Save As (Ctrl+Shift+S) — opens a file dialog to choose the save location and file name.

Once saved, the file appears in the file browser when you navigate to the folder containing it. The saved .xrfx file contains the full result: best structure, reflectivity curves, convergence history, and the original configuration — everything needed to reproduce or continue the run.

Output directory files: The xrccmd optimizer also writes intermediate files (curves, population, checkpoint) to the output directory specified in the configuration. The .xrfx file created by File > Save bundles the most important data into a single portable file.

Typical Workflow

  1. Click New Run and configure targets, element pool, and parameter ranges.
  2. Click OK and switch to the Progress tab to watch convergence.
  3. When the run completes (or you Stop it), review the result in the Curves tab.
  4. If the result is promising, use File > Save As to save the .xrfx file to your working folder.
  5. To refine, click Edit Run, increase iterations or adjust ranges, and run again.
  6. Save the improved result over the previous file (Ctrl+S) or as a new file (Ctrl+Shift+S).
