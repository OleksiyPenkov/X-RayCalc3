# XRFCalc Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build XRFCalc, a standalone Delphi VCL application for multi-target X-ray multilayer mirror optimization with live monitoring.

**Architecture:** Shared engine units extracted from `XRC_CMD/units/` into `Universal/` directory. XRFCalc and xrccmd both compile against these shared units. The GUI runs optimization in a background thread with event-driven chart updates.

**Tech Stack:** Delphi RAD Studio 37.0, VCL, TChart (TeeChart), FastMath, DUnitX (tests)

**Spec:** `docs/superpowers/specs/2026-03-16-xrfcalc-design.md`

**Extraction strategy:** The `cmd_unit_universal_*.pas` files move to `Universal/` with renamed unit names. Their dependencies (`cmd_unit_types`, `cmd_math_globals`) stay in `XRC_CMD/units/` and are accessed via search path. `RefCalc` is extracted from `cmd_unit_calc.pas` to avoid the OmniThreadLibrary dependency. The `math_complex` unit in `Math/` is shared as-is. Note: `math_complex` function names are `MulRZ`, `MulZZ`, `AddZZ`, `AddZR`, `SubZZ`, `DivZZ`, `SqrtZ`, `ExpZ`, `AbsZ`, `ToComplex` — NOT the `CMult`/`CAdd` style.

6. **Events**: After each iteration, build `TIterationData` and fire `OnIteration`. After the loop, compute curves via `FFitness.GetCurve(...)` for each target and fire `OnCompleted`. Wrap the entire body in try/except, firing `OnError` on exception.

6. **Cancellation**: Check `FCancelled` at the top of each iteration.

```pascal
unit unit_xrf_thread;

interface

uses
  System.SysUtils, System.Classes,
  unit_universal_types, unit_universal_optimizer;

type
  TOptimizationThread = class(TThread)
  private
    FConfig: TUniversalConfig;
    FOptimizer: TUniversalOptimizer;
    FOnIteration: TIterationEvent;
    FOnCompleted: TCompletionEvent;
    FOnError: TErrorEvent;
    FLastUpdateTick: Cardinal;
    procedure DoIteration(const Data: TIterationData);
    procedure DoCompleted(const Data: TIterationData;
      const Curves: TArray<TCurveData>);
    procedure DoError(const ErrorMsg: string);
  protected
    procedure Execute; override;
  public
    constructor Create(const AConfig: TUniversalConfig);
    procedure CancelOptimization;
    property OnIteration: TIterationEvent read FOnIteration write FOnIteration;
    property OnCompleted: TCompletionEvent read FOnCompleted write FOnCompleted;
    property OnError: TErrorEvent read FOnError write FOnError;
  end;

implementation

uses
  Winapi.Windows;

constructor TOptimizationThread.Create(const AConfig: TUniversalConfig);
begin
  inherited Create(True); // create suspended
  FreeOnTerminate := False;
  FConfig := AConfig;
  FLastUpdateTick := 0;
end;

procedure TOptimizationThread.CancelOptimization;
begin
  if Assigned(FOptimizer) then
    FOptimizer.Cancel;
end;

procedure TOptimizationThread.DoIteration(const Data: TIterationData);
var
  Tick: Cardinal;
  DataCopy: TIterationData;
begin
  // Throttle UI updates to ~200ms
  Tick := GetTickCount;
  if (Tick - FLastUpdateTick) < 200 then
    Exit;
  FLastUpdateTick := Tick;

  DataCopy := Data;
  if Assigned(FOnIteration) then
    TThread.Queue(nil,
      procedure
      begin
        FOnIteration(DataCopy);
      end);
end;

procedure TOptimizationThread.DoCompleted(const Data: TIterationData;
  const Curves: TArray<TCurveData>);
var
  DataCopy: TIterationData;
  CurvesCopy: TArray<TCurveData>;
begin
  DataCopy := Data;
  CurvesCopy := Curves;
  if Assigned(FOnCompleted) then
    TThread.Queue(nil,
      procedure
      begin
        FOnCompleted(DataCopy, CurvesCopy);
      end);
end;

procedure TOptimizationThread.DoError(const ErrorMsg: string);
var
  Msg: string;
begin
  Msg := ErrorMsg;
  if Assigned(FOnError) then
    TThread.Queue(nil,
      procedure
      begin
        FOnError(Msg);
      end);
end;

procedure TOptimizationThread.Execute;
begin
  FOptimizer := TUniversalOptimizer.Create(FConfig);
  try
    FOptimizer.OnIteration := DoIteration;
    FOptimizer.OnCompleted := DoCompleted;
    FOptimizer.OnError := DoError;
    FOptimizer.Run;
  finally
    FOptimizer.Free;
    FOptimizer := nil;
  end;
end;

end.
```
